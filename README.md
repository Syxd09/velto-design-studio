# Velto Design Studio

Build the UI for Velto, an AI-powered platform for interior designers and architecture studios to create professional interior design presentations and client proposals.

Velto should help designers turn their project ideas, reference images, material selections, design concepts, and client requirements into polished, professional presentations. It should also support project management, design boards, material and finish selections, quotations, bills of quantities, and client-ready proposals.

The platform should feel like a complete, practical workspace for interior design professionals, helping them save time, organize their projects, and present their ideas to clients more effectively.

Focus on creating a high-quality, modern, intuitive, and fully responsive UI with realistic sample data and functional interactions. Explore the best way to present this product and its features yourself. Do not limit the design to a generic dashboard template.

For now, focus on building the frontend UI and user experience. Use mock data wherever necessary, and keep the implementation structured so backend functionality and AI integrations can be added later.
